# Dhanush Poojary | Cinematic React Portfolio

A state-of-the-art interactive developer portfolio built with React.js using a custom Midnight Glassmorphism aesthetic.

### Features
- **Cinematic Loader**: Premium percentage loader with tracking bar.
- **Glassmorphism Typography**: Beautiful glow-text and cards using standard web-kit filters.
- **Animated Sync Grid**: Beautiful synthwave background panning grid.
- **Magic Mixed-Blend Cursor**: Highly optimized pure-CSS inverted dot cursor.
- **Responsive Layout**: Designed perfectly for both desktop and mobile layouts.

### Built With
- React.js / Vite
- Pure Custom CSS

### Running Locally
1. `npm install`
2. `npm run dev`
